## 2. Iconography & Accessibility Standards

- **Icon Set**: Clean inline SVG icons across all 25 public & authenticated views. No emojis used as UI icons.
- **Glassmorphism**: Applied subtly on hero cards and statistics panels without degrading contrast.
- **Micro-Animations**: Hover transforms, smooth transitions, and pop-up modals configured with accessibility support for `prefers-reduced-motion`.
