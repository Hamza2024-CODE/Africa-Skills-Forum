# Project & Workspace Customization Rules

## UI Design & Iconography Law
- **NO RAW EMOJIS IN UI**: Never use raw unicode emojis (`📋`, `⏳`, `✅`, `❌`, `🔍`, `📄`, `🗑️`, `👁️`, etc.) in production UI components, buttons, tables, badges, or admin pages.
- **ALWAYS USE VECTOR SVG ICONS**: Always use clean, sharp inline SVG vector icons (Tailwind CSS colored Heroicons / Lucide style icons) for all status badges, buttons, modals, dropdowns, and counter cards.
